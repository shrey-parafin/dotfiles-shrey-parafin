# Communication preferences

- Always expand acronyms and initialisms on first use in each reply, using the form `Full Term (ACRONYM)`.
- Do not assume the user already knows an acronym. If an expansion is ambiguous or uncertain, explain the ambiguity or avoid the abbreviation.

# pstack in Codex

When using a pstack skill, first read `~/.codex/skills/poteto-mode/../../CODEX.md` (the path traverses the skill symlink). If that path is unavailable, locate `CODEX.md` beside the installed pstack `skills/` directory. This compatibility note applies only when pstack is invoked.
